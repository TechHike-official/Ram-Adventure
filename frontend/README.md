# Ram Adventure – Munnar Jeep Safari Website

Ram Adventure is a fast, SEO-optimized, serverless web application built using **Next.js**.  
It is designed to showcase jeep safari packages in the Munnar region and allow customers to view tours and book appointments online.

---

## Features

- Built with **Next.js (App Router)**
- SEO-optimized for tour listings and booking pages
- Fully responsive mobile-first UI
- Serverless API routes for bookings and backend actions
- Dynamic tour pages with slug-based routing
- Image optimization for fast performance
- Optional payment gateway integration (Stripe/Razorpay)

---

## Tech Stack

- Next.js 14+
- React
- Tailwind CSS (optional)
- Vercel Serverless Functions
- Stripe / Razorpay (optional)
